# sap-test-strategy-agent

AI agent built with Claude Code that generates SAP S/4HANA test strategy artifacts — test scenarios, risk
classification, entry/exit criteria, and traceability notes — from a business process description and
module scope. Applies the same "ask, don't assume" and "flag what can't be validated" discipline as the
sibling Travel Agent project, adapted to SAP test-design judgment.

See `CLAUDE.md` for the operating rules this agent follows on every run.
